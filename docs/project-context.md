# 项目背景与已确定决策

来源：用户于 2026-10-09 提供的讨论总结。本文归纳已确定约束；外部项目调研属于用户提供的历史结论，尚未重新核实。

## 为什么做

用户学习数据结构与算法，目标是实习和本科毕业就业。系统帮助用户识别算法模式、主动回忆、独立解题，用间隔重复减少遗忘。学习目标是深度掌握覆盖核心模式的 150–200 道题，而不是只累积题量。

## 第一阶段

- 纯前端、本地 Web App，不需要后端或账号。
- 使用 Vite、React 18、TypeScript、Tailwind CSS、Dexie / IndexedDB、dexie-react-hooks、ts-fsrs、crypto.randomUUID()。
- 核心逻辑不依赖 UI 框架；存储职责与 UI 分离。先保持方案中的简单文件结构，不增加多包工程。
- 手动粘贴题目文本和链接，不自动抓取页面。
- AI 返回标题、难度、主要模式、次要模式、核心洞察、代码骨架和前置知识。
- 模式固定为执行方案中的 16 种，不能新增或自由生成。
- AI 返回字段需要校验和默认值；无法解析的响应需清楚报错，不能伪装为导入成功。
- 题目存 IndexedDB，API Key、Base URL、Model 存 localStorage。
- 深色主题，导入 / 题库 / 复习三个 Tab，另有 AI 设置入口。
- 复习先尝试，再揭示洞察与骨架；Again / Hard / Good / Easy 评分后更新卡片。
- FSRS 使用默认参数和 enable_fuzz，不自行调整参数。讨论中的固定时间间隔只是理念示例，不是 FSRS 的硬编码日程。
- 交付可运行项目、README 和导入 / 题库 / 复习页截图。

## 学习理念与远期范围
